# AVP Timer — downloads

Speaker clock for live events: a countdown on a second screen, control via
Bitfocus Companion / Stream Deck, and displays anywhere on the network.

## Download

Open **[Releases](../../releases)** (on the right of this page) and pick the newest version.

| Device | File |
|---|---|
| Windows 10/11 | `AVP Timer_<version>_x64_en-US.msi` |
| Chromebook | `avp-timer-chromeos-<version>.swbn` |
| Mac (Apple silicon) | `AVP Timer_<version>_aarch64.dmg` |
| Mac (Intel) | `AVP Timer_<version>_x64.dmg` |
| Linux (Ubuntu/Debian) | `avp-timer_<version>_amd64.deb` |
| Companion module | `avp-timer-companion-<version>.tgz` |

Each release also includes the installation guide for your device.

## Updates

The app tells you when a new version is available (⚙ → About AVP Timer).
