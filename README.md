# AVP Timer — downloads

Sprekersklok voor live-evenementen: een countdown op een tweede scherm,
bediening via Bitfocus Companion / Stream Deck en schermen in het netwerk.

## Downloaden

Open **[Releases](../../releases)** (rechts op deze pagina) en kies de nieuwste versie.

| Toestel | Bestand |
|---|---|
| Windows 10/11 | `AVP Timer_<versie>_x64_en-US.msi` |
| Chromebook | `avp-timer-chromeos-<versie>.swbn` |
| Mac (Apple-chip) | `AVP Timer_<versie>_aarch64.dmg` |
| Mac (Intel) | `AVP Timer_<versie>_x64.dmg` |
| Linux (Ubuntu/Debian) | `avp-timer_<versie>_amd64.deb` |
| Companion-module | `avp-timer-companion-<versie>.tgz` |

Bij elke versie staat ook de handleiding voor jouw toestel.

## Updates

De app meldt zelf wanneer er een nieuwe versie is (⚙ → About AVP Timer).
